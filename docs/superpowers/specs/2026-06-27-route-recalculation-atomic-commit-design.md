# Route Recalculation Atomic Commit Design

## 결론

경로 다시 계산이 성공했을 때만 Standard/CarryME 화면 상태를 한 번에 갱신한다.

## 목표

행선지 편집 중에는 기존 일정 화면을 유지하고, 경로 계산 성공 시점에만 비교 카드, 지도, 타임라인, 총 이동 시간, 절약 시간을 같은 기준으로 갱신한다.

## 갱신 정책

- 행선지 입력, 추천 장소 선택, 드래그 순서 변경, 교통수단 변경 중에는 아래 일정 영역을 바꾸지 않는다.
- `경로 다시 계산`을 누르면 Standard와 CarryME 경로를 모두 계산한다.
- 두 경로가 모두 성공하면 하나의 상태 변경으로 화면 전체를 갱신한다.
- 하나라도 실패하면 기존 화면을 유지하고 오류 메시지만 표시한다.

## 갱신 대상

- Standard 비교 카드
- CarryME 비교 카드
- 지도 마커/경로
- Standard 일정 타임라인
- CarryME 일정 타임라인
- 총 이동 시간
- 절약 시간

## 상태 구조

- 편집 중 행선지는 초안 상태로 둔다.
- 확정된 화면은 마지막 성공 계산 결과 상태를 기준으로 렌더링한다.
- API 실패 또는 부분 실패 결과는 확정 상태에 반영하지 않는다.

## 테스트 기준

- 행선지 편집만으로는 타임라인이 바뀌지 않는다.
- 경로 계산 성공 후 Standard/CarryME 타임라인이 함께 바뀐다.
- 경로 계산 실패 시 기존 타임라인과 요약이 유지된다.
- 성공 전후 지도/비교 카드/타임라인의 행선지 순서가 일치한다.
