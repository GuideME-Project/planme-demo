# PlanME 국내 길안내 기술검토 메모

## 현재 적용안

확인일: 2026-06-30

PlanME 현재 구현 방향은 티맵을 제외하고, 아래 조합으로 정리합니다.

- 지도 표시: 네이버 지도 SDK
- 자동차 경로: 네이버 Directions API
- 대중교통/도보 경로: ODsay API
- 티맵: 현재 구현 경로에서 제외

ODsay 공식 문서 기준으로 대중교통 경로 검색은 출발지/도착지 좌표 중심이며, PlanME의 여러 경유지를 한 번에 넣는 공개 파라미터는 확인되지 않았습니다. 따라서 경유지가 여러 개면 구간별로 요청하고, 동일 요청 캐시와 순차 호출로 호출량을 줄입니다.

## 결론

아래 내용은 2026-06-29 티맵 중심 검토 기록입니다. 현재 적용안은 위의 네이버 + ODsay 조합입니다.

PlanME 웹 안에서 국내 경로를 직접 보여주려면 교통수단별로 가능한 범위가 다릅니다.

- 지도 표시, 마커, 선 그리기: 가능
- 자동차 경로선: 가능
- 도보 경로선: 가능
- 대중교통 경로선: 일부 가능
- KTX 선로 경로선: 현재 확인 기준으로 지도에 그릴 상세 좌표 없음

따라서 `티맵이면 국내 대중교통/KTX 경로선을 모두 그릴 수 있다`고 보고하면 안 됩니다.

## 대중교통 API에서 분리해야 할 점

대중교통 API가 있다고 해서 모든 대중교통 구간을 지도선으로 그릴 수 있는 것은 아닙니다.

API 응답에는 경로 정보와 지도선 좌표가 함께 올 수 있지만, 지도선 좌표의 품질은 교통수단과 구간에 따라 다릅니다.

- 버스/지하철/도보 구간: 상세 좌표가 여러 개 내려오는 경우가 있음
- KTX/항공 구간: 실제 테스트에서 시작점/끝점 2개 좌표만 확인됨
- 좌표 2개짜리 구간: 실제 도로나 선로가 아니라 두 지점을 이은 직선으로 보임

## 실제 테스트 결과

### 1. 인천공항 -> 부산 공연장

티맵 대중교통 API가 항공 중심 경로를 선택했습니다.

- 김포공항 -> 김해국제공항 항공 구간: 좌표 2개
- 부산 시내 버스/도보 구간: 상세 좌표 다수
- 지도 표시 판단: 항공 구간은 제외하고, 상세 좌표가 있는 부산 시내 구간만 표시

### 2. 서울역 -> 부산역

KTX 경로 정보는 반환됐지만, 선로를 따라가는 상세 좌표는 확인되지 않았습니다.

- 교통수단: 기차
- 노선명: KTX 서울-부산
- 지도선 좌표: 시작점/끝점 2개
- 지도 표시 판단: KTX 구간은 지도선으로 표시하지 않음

### 3. 김해국제공항 -> 부산 공연장

부산 시내 버스/도보 구간은 상세 좌표가 내려왔습니다.

- 버스/도보 구간: 상세 좌표 다수
- 지도 표시 판단: 지도 위 경로선 표시 가능

### 4. 고속/시외버스

추가 테스트가 필요합니다.

고속/시외버스의 상세 좌표 반환 여부는 아직 확정하지 않습니다.

## 지도선 렌더링 원칙

PlanME 화면에서는 좌표가 있다고 해서 모두 선으로 그리면 안 됩니다.

- 좌표가 3개 이상인 구간만 지도선으로 표시
- 좌표가 2개뿐인 구간은 시작점/끝점만 있는 데이터로 보고 표시하지 않음
- 상세 좌표가 없는 구간을 임의 직선으로 연결하지 않음
- 여러 구간 사이에 빈 구간이 있으면 끊긴 상태로 둠
- 사용자가 선택한 교통수단과 실제 API가 선택한 교통수단이 다르면 화면에 표시해야 함

## 운영 리스크

### 1. KTX 강제 선택 문제

인천공항에서 부산으로 이동하는 시나리오에서 티맵이 항공 경로를 우선 선택할 수 있습니다.

KTX 시나리오를 강제로 만들려면 단순 출발지/도착지 호출만으로는 부족할 수 있습니다.

가능한 방식:

- 인천공항 -> 서울역
- 서울역 -> 부산역
- 부산역 -> 공연장

다만 이 방식도 KTX 선로 상세 좌표를 보장하지 않습니다.

### 2. 지도선과 실제 이동수단의 불일치

KTX나 항공처럼 상세 좌표가 없는 구간을 직선으로 그리면 사용자가 실제 경로로 오해할 수 있습니다.

이 구간은 선을 숨기고, 텍스트 일정에서 이동수단과 시간을 설명하는 편이 안전합니다.

## 현재 구현 기준

현재 PlanME 데모는 네이버/ODsay 응답 중 지도에 그릴 수 있는 상세 좌표만 지도선으로 사용합니다.

적용 기준:

- 자동차: 네이버 Directions 상세 좌표 사용
- 도보: ODsay 상세 좌표 사용
- 대중교통: ODsay 구간별 상세 좌표가 3개 이상일 때만 사용
- KTX/항공: 좌표가 2개뿐이면 사용하지 않음

## 외부 공유용 요약

티맵을 사용하면 PlanME 웹에서 지도 표시, 마커, 자동차/도보 경로선, 일부 대중교통 구간 표시가 가능합니다.

다만 KTX 구간은 현재 확인된 응답에서 선로를 따라가는 상세 좌표가 아니라 시작점/끝점 2개 좌표만 내려와 지도선으로 표시하면 직선이 됩니다.

따라서 KTX 구간은 지도 위 선으로 표현하지 않고, 일정 텍스트에서 이동수단과 시간을 안내하는 방식으로 분리하는 것이 안전합니다.
