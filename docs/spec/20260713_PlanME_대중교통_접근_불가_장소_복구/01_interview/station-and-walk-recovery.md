# 정류장 및 도보 구간 복구

## 목적

- 이 주제를 확인하는 이유: 목적지 주변에 ODsay가 자동 선택하는 정류장이 없어도, 더 먼 정류장과 마지막 도보를 조합해 일정을 완성할 수 있어야 한다.
- 이 주제가 불명확하면 생기는 리스크: 가까운 정류장을 찾았다는 이유만으로 산·강·단절 도로를 직선으로 연결하거나, 실제로 걸을 수 없는 구간을 성공 처리할 수 있다.

## Questions

1. 목적지 주변 정류장을 별도로 검색할 수 있는가?
2. ODsay 도보 길안내에는 어떤 제한과 실패 조건이 있는가?
3. AI 추천 장소와 사용자 지정 장소에 같은 도보 허용 기준을 적용할 것인가?
4. 사용자 지정 장소의 실제 도보 경로가 없으면 이동시간을 추정해 보정할 수 있는가?
5. 실제 도보 경로가 없는 구간에 지도 경로선을 표시할 것인가?

## Answers

1. ODsay 반경 내 대중교통 POI 검색(`pointSearch`)으로 버스정류장·지하철역·기차역·터미널 후보와 좌표를 조회할 수 있다.
2. 전용 도보 길찾기(`searchWalkPathV2`)는 직선거리 30km 이내에서 요청할 수 있다. 거리 이내라도 출발지 또는 도착지를 보행 도로망에 연결하지 못하거나 경로가 없으면 실패할 수 있다.
3. AI 추천 장소는 정류장에서 실제 도보 30분 이내일 때만 유지한다. 사용자 지정 장소는 자동 교체하지 않고 편도 90분까지 허용한다.
4. 실제 도보 경로가 없으면 직선거리, 우회계수, 보수적인 보행속도와 여유시간으로 이동시간을 추정한다. 정확한 계수 선택은 구현 판단에 맡기되 대표 사례로 검증한다.
5. 추정 구간에는 실제 경로처럼 보이는 선을 만들지 않는다.

## Score

- 현재 불명확성 점수: `0.20`
- 목표 임계값: Standard `0.20`
- 점수 근거: 복구 순서와 사용자 유형별 허용 시간이 확정됐다. 공급자 계약, 정류장 검색 최대 반경과 추정 계수는 기술 검증이 남아 있다.
- 다음에 낮춰야 할 불확실성: ODsay 운영 계약과 남해 산악 목적지에서의 실제 도보 커버리지를 검증한다.

## Confirmed

- 대중교통 오류 코드 `4`가 발생하면 목적지 주변 정류장 후보를 별도로 검색한다.
- 후보 정류장마다 이전 장소에서 정류장까지 대중교통 경로가 실제로 존재하는지 검증한다.
- 정류장에서 목적지까지는 ODsay 전용 도보 길찾기를 먼저 사용한다.
- AI 추천 장소의 마지막 도보 상한은 편도 30분이다.
- 사용자 지정 장소의 자동 최종화 가능한 마지막 도보 상한은 편도 90분이다.
- 도보 API 실패 시 보수적인 추정시간을 사용할 수 있다.
- 추정 구간은 경로 좌표 없이 시간만 제공한다.
