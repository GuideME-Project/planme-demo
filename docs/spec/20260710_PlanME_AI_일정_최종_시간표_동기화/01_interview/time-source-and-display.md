# 시간 계산 및 표시 기준

## 목적

- 이 주제를 확인하는 이유: AI 예상 이동 시간이 네이버 계산 후 바뀌는 현상을 제거하고, 모든 화면에서 같은 실제 이동 시간을 제공한다.
- 이 주제가 불명확하면 생기는 리스크: 체류 시간이 총 이동 시간에 섞이거나 Standard와 CarryME가 서로 다른 기준으로 비교될 수 있다.

## Questions

1. 네이버 길찾기가 끝날 때까지 어떤 내용을 표시하는가?
2. ChatGPT 위젯과 상세 웹의 최종 이동 시간 기준은 무엇인가?
3. AI가 만든 장소 순서와 시간표를 다시 계산하는가?
4. 총 이동 시간에 관광·식사·체류 시간을 포함하는가?

## Answers

1. 장소 순서와 지도 마커만 먼저 표시하고 이동 시간·총 이동 시간·지도 경로는 `계산 중`으로 숨긴다. 계산이 끝나면 최종 값을 한 번에 표시한다.
2. 두 화면 모두 네이버 길찾기 계산을 반영한 동일한 순수 이동 시간과 지도 경로를 사용한다. AI가 만든 예상 총 이동 시간은 노출하지 않는다.
3. 다시 계산하지 않는다. AI가 만든 장소 순서와 시간표 내용은 그대로 유지한다.
4. 총 이동 시간은 관광·식사·체류 시간을 제외한 네이버 길찾기 구간 시간의 합계로 정의한다.

## Score

- 현재 불명확성 점수: `0.10`
- 목표 임계값: `Standard 0.20`
- 점수 근거: 이동 시간의 제공자, 합산 범위, 기존 시간표 유지와 계산 중 표시 기준이 확정되었다.
- 다음에 낮춰야 할 불확실성: 자동차와 대중교통의 성공 응답 판정은 설계 단계에서 확인해야 한다.

## Confirmed

- AI 장소 순서와 시간표 내용은 네이버 결과로 변경하지 않는다.
- 계산 중에서 최종 이동 시간과 지도 경로로 한 번만 전환한다.
- 총 이동 시간과 하루 일정의 길이는 같은 값으로 취급하지 않는다.
- 절약 시간 비교는 같은 기준으로 계산된 Standard와 CarryME의 길찾기 이동 시간 차이를 사용한다.
- 체류 시간 데이터는 새로 추가하지 않는다.

## Open Questions
