# 서버 계산 및 위젯 동기화

## 목적

- 이 주제를 확인하는 이유: ChatGPT 위젯과 상세 웹이 서로 다른 이동 시간과 지도 경로를 보여주거나 탭 전환 때 다시 계산하는 문제를 없앤다.
- 이 주제가 불명확하면 생기는 리스크: 위젯에는 AI 예상 이동 시간이 남고 웹에서만 길찾기 이동 시간이 표시되거나, 새로고침마다 결과가 달라질 수 있다.

## Questions

1. ChatGPT 위젯은 언제 어떤 일정 정보를 표시하는가?
2. 여러 일차 일정은 언제 완료로 처리하는가?
3. Standard와 CarryME 중 하나만 성공하면 다른 쪽 결과를 재사용하는가?
4. 계산 결과는 어디에서 재사용하는가?
5. 계산 중 위젯은 몇 개를 표시하는가?

## Answers

1. 최종 확정된 설계 방향에서는 ChatGPT의 도구 실행 상태만 표시하고, 서버 계산 완료 후 최종 위젯을 한 번 표시한다.
2. 모든 일차의 Standard와 CarryME 경로가 모두 성공해야 전체 일정을 완성으로 처리한다. 일부 이동 시간이나 지도 경로만 먼저 노출하지 않는다.
3. 한쪽 결과를 다른 쪽에 복사하지 않는다. 두 경로의 행선지 순서가 달라 시간·경로·절약 시간이 달라질 수 있기 때문이다.
4. 최종 이동 시간과 지도 경로 계산 결과를 서버에 저장하고, ChatGPT 위젯과 상세 웹은 같은 저장 결과만 읽는다. 새로고침과 일차 탭 전환만으로는 재계산하지 않는다.
5. 계산 중 위젯은 하나만 표시한다. 계산 과정에서 위젯을 반복 생성하지 않는다.

## Score

- 현재 불명확성 점수: `0.15`
- 목표 임계값: `Standard 0.20`
- 점수 근거: 사용자에게 보이는 상태 흐름, 전체 완료 조건, 저장 결과 공유와 위젯 중복 방지가 확정되었다.
- 다음에 낮춰야 할 불확실성: 서버 계산 작업의 구체적인 저장소와 위젯 갱신 방식은 설계가 필요하다.

## Confirmed

- 위젯과 웹은 동일한 AI 시간표 내용, 길찾기 이동 시간, 지도 경로를 보여준다.
- 계산 전 AI 예상 이동 시간이나 부분 완료된 이동 시간·지도 경로를 노출하지 않는다.
- 모든 일차와 두 경로를 하나의 최종 결과로 원자적으로 확정한다.
- 저장된 최종 결과는 페이지 새로고침과 탭 전환에서 재사용한다.
