## 핵심 확정사항

- AI가 만든 장소 순서와 시간표 내용은 유지한다.
- AI가 만든 예상 총 이동 시간은 사용자에게 노출하지 않는다.
- 총 이동 시간은 관광·식사·체류 시간을 제외한 네이버 길찾기 구간 시간의 합계다.
- 서버가 모든 일차의 Standard·CarryME 경로를 계산하고, 성공한 최종 결과를 저장한다.
- ChatGPT 위젯과 상세 웹은 동일하게 저장된 이동 시간과 지도 경로를 사용한다.
- 계산 중에는 장소 순서와 지도 마커만 표시하고 이동 시간·총 이동 시간·지도 경로는 숨긴다.
- 모든 일차의 Standard·CarryME 계산이 성공해야 전체 일정이 완성된다.
- 전체 좌표 검색과 길찾기 계산은 재시도를 포함해 40초 안에 완료한다.
