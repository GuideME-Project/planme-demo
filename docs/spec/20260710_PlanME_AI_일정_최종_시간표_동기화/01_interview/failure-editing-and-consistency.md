# 실패·편집·정합성 처리

## 목적

- 이 주제를 확인하는 이유: 좌표 검색이나 길찾기 실패, 중복 편집, 늦게 도착한 응답이 최종 경로를 손상하지 않게 한다.
- 이 주제가 불명확하면 생기는 리스크: 행선지·이동 시간·지도 경로가 서로 다른 버전으로 저장되거나 이전 계산이 최신 편집을 덮어쓸 수 있다.

## Questions

1. 좌표가 없는 장소는 어떻게 처리하는가?
2. 전체 계산 제한시간과 재시도 기준은 무엇인가?
3. 최종 계산이 실패하면 위젯에서 어떻게 안내하는가?
4. 행선지나 이동 수단을 편집하면 기존 결과를 어떻게 처리하는가?
5. 편집 후 재계산이 실패하면 변경을 유지하는가?
6. 계산 중 추가 편집을 허용하는가?

## Answers

1. 네이버 장소 검색에서 대표 좌표를 자동 선택하고 길찾기를 진행한다. 하나라도 좌표를 확보하지 못하면 전체 일정 계산을 실패 처리한다.
2. 좌표 검색과 길찾기 재시도를 포함한 전체 제한시간은 40초다. 길찾기가 일시적으로 실패하면 실패한 구간만 1회 자동 재시도한다.
3. 성공 시 최종 이동 시간과 경로가 포함된 위젯을 표시한다. 실패 시 위젯에 버튼 없이 `일정을 완성하지 못했습니다. 다시 요청해주세요.`라고 표시한다.
4. 행선지 또는 일정 전체 이동 수단이 변경된 경우에만 전체 경로를 다시 계산한다. 기존 이동 시간과 경로는 숨기고 `최종 일정 다시 계산 중`을 표시한다.
5. 편집은 새 계산까지 성공해야 저장한다. 실패하면 편집을 취소하고 마지막 성공 일정으로 복원한 뒤 상세 웹에서 `변경한 일정의 경로를 계산하지 못했습니다`라고 안내한다.
6. 계산 중에는 행선지 교체, 이동 수단 변경, 경유지 추가, 경로 재계산 버튼을 비활성화한다.

## Score

- 현재 불명확성 점수: `0.15`
- 목표 임계값: `Standard 0.20`
- 점수 근거: 좌표 실패, 제한시간, 재시도, 초기 실패와 편집 실패의 사용자 경험, 동시 편집 방지가 확정되었다.
- 다음에 낮춰야 할 불확실성: 네이버 오류 유형별 재시도 가능 여부와 계산 작업 취소 방식은 설계가 필요하다.

## Confirmed

- 좌표 검색과 길찾기는 하나의 40초 제한 안에서 처리한다.
- 일부 성공 결과를 최종 일정으로 저장하지 않는다.
- 편집 저장과 계산 결과 저장은 함께 성공하거나 함께 취소되어야 한다.
- 출발지를 유지한 자동 일정 재생성은 후속 개선 후보이며 이번 범위에는 포함하지 않는다.

## Open Questions

- 40초 만료 시 이미 실행 중인 외부 요청을 취소하는 구체적인 방식은 미정이다.
- 대중교통에서 일부 지도 형상만 제공되는 응답을 성공으로 볼지 미정이다.
