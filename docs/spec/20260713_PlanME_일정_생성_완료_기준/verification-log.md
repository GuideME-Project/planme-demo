## 로컬 실제 화면 검증

### 다일 일정

`generated-양양-3일-여행-추천-3d-uxub3t`에서 확인했다.

- 1일 차: 강동역 5호선 출발, 쏠비치 양양 종료
- 2일 차: 쏠비치 양양 출발, 쏠비치 양양 종료, 같은 숙소 연박으로 중복 짐 배송 없음
- 3일 차: 쏠비치 양양 출발, 강동역 5호선 복귀
- 3일 차 CarryME: 짐 강동역 5호선 선도착과 여행자 강동역 5호선 도착 표시
- 모든 장소명은 확정 정류장 이름과 일치하며 반복 지역 접두어 없음

### 반대 이동 수단 재계산

- 자동차 → 대중교통: 저장 성공, 새로고침 후 `transit`과 대중교통 시간표 문구 유지
- 대중교통 → 자동차: `generated-양양-3일-여행-추천-3d-uxub3t`에서 저장 성공
- 대중교통 → 자동차 새로고침 후 `drive`와 자동차 시간표 문구 유지
- 새로고침 뒤 3일 차 강동역 복귀와 강동역 짐 선도착 유지
- 성공 후 기존 이동 수단 문구가 혼합되어 남지 않음

### 지도

- 로컬 네이버 SDK 실패 조건에서 현재 3일 차 Standard 정류장 네 개를 순서대로 표시했다.
- 쏠비치 양양 출발과 강동역 5호선 복귀를 모두 표시했다.
- 과거 데모의 인천공항·서면 호텔·부산 공연장·BTS 공연 문구는 표시하지 않았다.
- 정적 지도 마커에 AI 장소명을 삽입할 때 HTML 이스케이프를 적용했다.
- 실제 네이버 지도 타일 드래그 검증은 자동 배포 후 운영 도메인에서 수행한다.

## 실행 중 정정한 검증 명령

- 파일 단위 린트 첫 실행은 npm 작업공간 기준 경로를 잘못 전달해 대상 파일을 찾지 못했다. 올바른 상대 경로로 재실행해 통과했다.
- 실 API 첫 실행은 확인 인자가 npm에 흡수되어 외부 호출 전에 중단됐다.
- 두 번째 실 API 실행은 환경파일을 셸에 불러오지 않아 외부 호출 전에 사전검사에서 중단됐다.
- 두 경우 모두 외부 API 호출 전 실패였으며, 민감값을 출력하지 않고 로컬 환경파일을 로드해 이후 여섯 시나리오를 모두 통과했다.
