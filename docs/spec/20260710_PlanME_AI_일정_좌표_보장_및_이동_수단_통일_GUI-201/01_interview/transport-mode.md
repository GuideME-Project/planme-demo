# 일정 전체 이동 수단

## 목적

- 이 주제를 확인하는 이유: 사용자 선택과 AI가 생성한 모든 경로 구간의 이동 수단이 일치해야 길안내 공급자와 지도 경로선이 같은 의미를 가진다.
- 이 주제가 불명확하면 생기는 리스크: 한 일정에 자동차·대중교통이 섞이거나 행선지별 선택으로 전체 이동 수단이 다시 깨질 수 있다.

## Questions

1. 이동 수단을 언제 사용자에게 물을 것인가?
2. 어떤 이동 수단을 지원할 것인가?
3. 사용자가 이동 수단을 이미 명시했을 때 다시 물을 것인가?
4. 선택한 이동 수단을 어느 경로와 구간까지 적용할 것인가?
5. 대중교통 내부 도보 구간을 어떻게 처리할 것인가?
6. 자동차와 대중교통 결과를 동시에 비교할 것인가?
7. 자연어 이동 수단 표현을 어떻게 분류할 것인가?

## Answers

1. 이동 수단은 일정 생성의 필수 조건이다. 명시되지 않았다면 숙소나 여행 취향 같은 선택 질문보다 먼저 물으며, 답변 전에는 일정을 생성하지 않는다.
2. 사용자 안내 문구는 `일정 안내는 자동차와 대중교통만 지원합니다. 어떤 이동 수단으로 안내할까요?`이고 선택지는 `자동차`, `대중교통` 두 개다.
3. 사용자가 자동차 또는 대중교통을 이미 명시하면 다시 묻지 않는다.
4. 선택한 이동 수단 하나를 기본 경로(Standard)와 CarryME 경로의 출발지부터 복귀지까지 모든 대표 구간에 적용한다.
5. 웹에서 도보 선택지와 `도보` 문구는 제거한다. 대중교통 승하차에 필요한 공급자 내부 도보 구간과 경로선은 유지한다.
6. 자동차와 대중교통 결과를 동시에 보여주거나 비교하지 않는다. 현재 선택된 이동 수단 하나의 결과만 표시한다.
7. `자차`, `렌터카`, `택시`, `버스`, `지하철`, `기차`, `KTX` 같은 표현의 자동 분류 범위는 확정하지 않았다. 자동차와 대중교통이 함께 언급되면 사용자에게 두 선택지 중 하나를 다시 묻는 방향은 유지한다.

## Score

- 현재 불명확성 점수: `0.28`
- 목표 임계값: `Standard 0.20`
- 점수 근거: 질문 시점, 지원 선택지, 전체 적용 범위, 도보 표시, 비교 제외는 확정됐지만 자연어 동의어 자동 분류 범위가 미결정이다.
- 다음에 낮춰야 할 불확실성: 자동차·대중교통으로 자동 분류할 자연어 표현 목록과 두 종류가 함께 언급된 경우의 판정 규칙.

## Confirmed

- 이동 수단이 없으면 반드시 먼저 질문한다.
- 지원 선택지는 자동차와 대중교통 두 개다.
- 사용자가 이미 하나를 명시하면 다시 묻지 않는다.
- 한 일정에는 전체 이동 수단 하나만 적용한다.
- 기본 경로(Standard)와 CarryME 경로는 같은 전체 이동 수단을 사용한다.
- 출발지, 방문지, 숙소, 복귀지 사이의 모든 대표 구간을 통일한다.
- 도보는 사용자 선택지와 대표 이동 수단 문구에서 제거한다.
- 대중교통 공급자 내부의 승하차 도보 구간은 유지한다.
- 자동차와 대중교통을 동시에 비교하지 않는다.
