# PlanME ChatGPT 일정 생성 실패 로그 개선 설계

## 목적

맞춤형 GPT 응답 크기와 GPT 앱 상세 저장 실패를 같은 요청 단위로 추적하고, 민감정보 없이 실패 단계를 식별하는 로그 계약을 정의한다.

## 현재 상태

- 맞춤형 GPT 요청과 GPT 앱 요청에 UUID 추적 식별자를 생성한다.
- MCP에서 웹 상세 저장 API까지 같은 추적 식별자를 전달한다.
- 맞춤형 GPT 성공 응답의 UTF-8 JSON 바이트 수를 기록한다.
- 상세 저장과 경로 제공자 실패를 안전한 내부 코드와 단계로 기록한다.
- 로그에는 일정 본문, 장소명, 좌표, 인증정보를 기록하지 않는다.
