# 일정 행 강조 표시 정책

## 목적

- 이 주제를 확인하는 이유: Standard와 CarryME 일정 행에 동일한 연한 초록 배경·체크·빨간 절약 칩이 반복되어 두 일정의 구분과 정보 우선순위가 흐려진다.
- 이 주제가 불명확하면 생기는 리스크: Standard 행이 CarryME 완료 상태처럼 보이고, 같은 절약 문구가 화면 여러 위치에서 중복 노출된다.

## Questions

1. Standard 일정 행의 연한 초록 배경과 체크를 유지할 것인가?
2. CarryME 일정 행의 연한 초록 배경과 체크를 유지할 것인가?
3. 일정 행 제목 옆의 빨간 절약 칩은 어떤 경우에 표시할 것인가?
4. CarryME 짐 배송 아이콘과 빛나는 효과는 유지할 것인가?
5. CarryME 총 이동 시간 상자 오른쪽의 빨간 절약 칩도 제거할 것인가?
6. 밝은 테마와 어두운 테마 중 어디에 적용할 것인가?

## Answers

1. 제거한다.
2. 제거한다.
3. 절약 없음과 실제 절약 발생 여부에 관계없이 Standard와 CarryME 일정 행에서는 모두 제거한다.
4. 짐 배송 사건을 구분할 수 있도록 유지한다.
5. 제거하지 않고 현재 모습으로 유지한다.
6. 두 테마에 모두 동일한 원칙을 적용한다.

## Score

- 현재 불명확성 점수: `0.03`
- 목표 임계값: `Standard 0.20`
- 점수 근거: 제거할 강조 요소와 유지할 CarryME 전용 요소, 하단 요약 예외가 모두 확정됐다.
- 다음에 낮춰야 할 불확실성: 없음. 구체적인 색상 토큰과 컴포넌트 분기는 설계 단계에서 정한다.

## Confirmed

- Standard와 CarryME 일정 행은 기본 배경을 사용한다.
- 일정 행의 연한 초록 배경·테두리와 오른쪽 초록 체크를 제거한다.
- 일정 행 제목 옆 빨간 칩은 `시간 절약 없음 · 짐 없이 바로 이동`, `약 N분 절약` 등 문구와 관계없이 모두 제거한다.
- CarryME 짐 배송 행의 배송 차량 아이콘과 빛나는 효과는 유지한다.
- CarryME 총 이동 시간 상자와 상자 오른쪽 빨간 절약 칩은 유지한다.
- 밝은 테마와 어두운 테마에 같은 표시 정책을 적용한다.
